For this project i opted to use Dynamic pages in Static Site Generation (SSG) mode.

Dynamic pages allow for faster and more simple pages creation, as only unique pages need to be made, and pages that are similar to great degree can be dynamically made using one simple template. And (SSG) pre-renders pages into static HTML files during the build process as opposed to Server-Side Rendering (SSR) that generates HTML dynamically on each request, enabling full personalization, real-time data, and user authentication.

SSG pre-renders pages into static HTML files during the build process, for fast delivery, excellent SEO, and very low costs, but it offers limited personalization and requires rebuilds for content updates. SSR generates HTML dynamically on each request, enabling full personalization, real-time data, and user authentication, but it incurs higher server costs, variable performance under load, and is more complex to create and maintain.
